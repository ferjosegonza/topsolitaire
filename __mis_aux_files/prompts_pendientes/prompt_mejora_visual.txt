Actúa como un diseñador de UX/UI y desarrollador frontend especializado en React, Tailwind CSS y diseño emocional.

Contexto:
Tengo un juego de solitario llamado "TopSolitaire" (topsolitaire.online), desarrollado con React + Vite + Tailwind CSS. Mi público objetivo principal son personas que disfrutan de los días nublados y lluviosos: introvertidos, sensibles, creativos, que buscan calma, introspección y confort.

Objetivo:
Necesito una adaptación visual completa del juego para conectar emocionalmente con este nicho. Quiero que el diseño transmita:
1. Calma y serenidad.
2. Intimidad y confort ("hygge").
3. Conexión con la naturaleza (lluvia, niebla, grises suaves).
4. Una sensación de "refugio" del mundo exterior.

Requerimientos técnicos:
- El proyecto usa React, Vite y Tailwind CSS.
- Se debe poder activar/desactivar este "modo lluvioso" mediante un toggle o switch en la interfaz (para que los usuarios que prefieren el diseño original también puedan usarlo).
- El cambio debe ser fluido y no afectar al rendimiento (sin recargas de página).
- Los assets (imágenes, sonidos) deben ser ligeros y optimizados para web.

Entregables que necesito:
1. Paleta de colores (códigos HEX) con al menos:
   - 1 color principal de fondo.
   - 1 color secundario para contenedores/cartas.
   - 2 colores de acento.
   - 1 color para texto principal.
   - 1 color para texto secundario.

2. Sugerencias de tipografía: qué familias tipográficas transmiten mejor la sensación de calma y confort.

3. Efectos visuales y animaciones:
   - Fondo animado (gotas de lluvia, niebla sutil, nubes lentas).
   - Sombras y texturas que simulen papel envejecido o tela.
   - Transiciones suaves (opacidad, desplazamiento) para todos los elementos.

4. Sonidos ambiente:
   - Recomendación de archivos de audio gratuitos (lluvia suave, truenos lejanos, viento) y cómo integrarlos con el sistema de audio existente (Howler.js).

5. Interfaz de usuario:
   - Diseño del toggle "Modo Lluvioso".
   - Cambios en los botones (más redondeados, menos agresivos).
   - Estilo de las cartas (tonos cálidos o fríos, texturas).

6. Código funcional:
   - El componente principal con el toggle y la lógica de cambio de tema (usando el contexto de React o clases CSS dinámicas).
   - Ejemplo de implementación del fondo animado con CSS puro (evitando dependencias pesadas).
   - Ejemplo de cómo cargar y reproducir los sonidos ambiente con Howler.js.

7. Estrategia de implementación:
   - Archivos a modificar/crear.
   - Estructura de carpetas recomendada.
   - Pasos para integrarlo sin romper el código existente.

Formato de respuesta:
- Entrega la respuesta en secciones claras con títulos en negrita.
- Los códigos deben estar en bloques de código con el lenguaje especificado (jsx, css, json, etc.).
- Prioriza la claridad, la sencillez y el rendimiento.
- Al final, incluye un resumen de los beneficios esperados para la aprobación de Google AdSense (aumento del tiempo en sitio, reducción de rebote, diferenciación).
