1. Estructura visual: Deben ser botones independientes y visualmente estandarizados con los demás elementos con los que están en una misma línea, deben ser responsivos, pueden tener texto junto al logo pero si el ancho disminuye por ejemplo en caso de mobile puede quedarse solo el logo.

5. Formato de entrega: Entrégame el código HTML estructurado y el CSS correspondiente de forma separada o dentro de una etiqueta <style>, listo para copiar, pegar y reemplazar con mis enlaces finales. Usa variables CSS para los colores principales si es posible para que pueda adaptarlo a la paleta de mi sitio.
