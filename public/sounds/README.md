# Sonidos para el Solitario

Coloca aquí los archivos de sonido:

- `card-flip.mp3` - Sonido al voltear una carta (0.3s)
- `card-place.mp3` - Sonido al colocar una carta (0.2s) 
- `deal.mp3` - Sonido al repartir cartas (0.5s)
- `win.mp3` - Sonido de victoria (1.5s)
- `click.mp3` - Sonido de clic (0.1s)

## Fuentes recomendadas:
- https://pixabay.com/sound-effects/
- https://freesound.org/
- https://www.zapsplat.com/

## Formato:
- MP3 o WAV
- Cortos (< 2s para la mayoría)
- Volumen bajo (para no ser intrusivos)
